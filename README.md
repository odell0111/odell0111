### Selected work

**[Turnstile Solver](https://github.com/odell0111/turnstile_solver)** — Python · GPL-3.0
An async server that solves Cloudflare Turnstile challenges in a real browser and
returns the token over a local REST endpoint. Proxy handling is first-class:
global, via environment, or rotated per browser context. 52 stars, 15 forks.

**[Account Manager](https://github.com/odell0111/account-manager)** — Android + Windows · Apache-2.0
A password and account manager built around multiple account types and password
import from file, with a fully bilingual interface. 450 release downloads. It
never goes online. Source is withheld deliberately, so it can't be forked into
insecure builds that put users' credentials at risk.

**[image-in-terminal](https://github.com/odell0111/image-in-terminal)** — Python · MIT · [PyPI](https://pypi.org/project/image-in-terminal/)
Renders images as coloured Unicode text in the terminal, from local files,
HTTP/HTTPS URLs or a whole directory. Published as v1.32.

**[Custom GUI SFX](https://github.com/odell0111/custom-gui-sfx)** — C# · .NET 6 · WPF
Packages an archive, custom info, links and images into a single self-extracting
`.exe` that runs on a machine with no unzip utility installed. 334 release
downloads.
